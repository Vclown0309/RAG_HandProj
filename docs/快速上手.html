RAG 演示台・快速上手

本文面向想直接体验的人：不用懂代码，照着做就能让一个本地 AI 问答系统跑起来 ——你的文档它来答，答案还能点开看依据。

一、你需要准备什么

东西 说明
Windows 电脑 有 NVIDIA 显卡体验最佳（llama.cpp CUDA 版）；无显卡也能跑，慢一些
Python 3.12 + uv 环境管理（不会装的看下方「常见问题」）
llama.cpp 模型推理程序，解压即可用
模型文件（GGUF） 两个：嵌入模型（负责把文字变成向量）+ 对话模型（负责生成回答）

模型文件放哪个目录都行，下面命令里的路径按你的实际情况改。

二、启动两个模型服务（最关键的一步）

模型服务是系统的 "发动机"，要先点着。打开两个 PowerShell 窗口分别运行：

服务 1：嵌入模型（端口 8081）

llama-server.exe -m D:\llamacpp_models\qwen3-embed\Qwen3-Embedding-8B-Q5_K_M.gguf --embedding --pooling last -c 8192 -b 8192 -ub 8192 --host 127.0.0.1 --port 8081

看到 listening on http://127.0.0.1:8081 即启动成功。

两个参数不能省：

  • --embedding：让模型以 "编码模式" 运行（输出向量而不是聊天）

  • --pooling last：取最后一层隐藏状态作为整句话的向量（Qwen 嵌入模型的官方要求）

服务 2：对话模型（端口 8080）

llama-server.exe -m D:\llamacpp_models\qwen3.5\Qwen3.5-4B-Q5_K_M.gguf -c 8192 -b 8192 -ub 8192 --host 127.0.0.1 --port 8080

注意：对话模型不带 --embedding 参数。

三、启动演示台

在项目目录（RAG_HandProj）打开 PowerShell：

uv sync
uv run uvicorn main:app --host 127.0.0.1 --port 8000

浏览器打开 http://127.0.0.1:8000，看到「RAG 演示台」页面即成功。

四、开箱体验

  1. 先装知识库：演示台右侧「知识库」区点「选择文件」→「上传入库」，支持 txt/md/markdown + doc/docx/xlsx/pptx/pdf/epub/rtf 等 15+ 种常见格式（anydoc 统一转 Markdown 入库；内置示例文档无需手动操作）；已入库的文档可点「删除」移除

  2. 提问：输入问题回车，模型会基于知识库回答

  3. 看依据：答案下方「参考源」列表点开，能看到模型依据的原文块 —— 每个知识点都能追到出处

  4. 管理知识库：演示页可直接上传 / 删除；需要批量或自动化时用接口 POST /library、DELETE /library/{文档名}（Swagger 或命令行）

五、常见问题

Q：提问报「服务不可用 /connection refused」

A：两个模型服务没起来或端口不对。检查 8080/8081 窗口是否还在运行，Test-NetConnection 127.0.0.1 -Port 8081 看是否通。

Q：换了嵌入模型后，检索结果不对

A：不同模型输出的向量维度不同（8B=4096，4B=2560），换模型后必须重建知识库：

uv run python -m scripts.build_kb "docs\RAG学习笔记01-模型服务与向量化输入.md" --reset

Q：上传文件报 400

A：分两种情况：① 文件本身有问题——扫描型 PDF（纯图片页）暂不支持、文件损坏/加密、内容为空；② 文件没问题但格式不支持——常见格式基本都支持（txt/md/markdown + doc/docx/xlsx/pptx/pdf/epub/rtf 等 15+ 种，anydoc 统一转 Markdown 入库），纯文本还会自动识别 UTF-8 / GBK / UTF-16 编码。报 400 时看错误提示，按提示处理即可。

Q：没有显卡能跑吗

A：能。llama.cpp 有 CPU 版，速度慢但可用；对话模型建议 4B 量化版。

Q：llama.cpp 升级后，启动命令不对了怎么办

A：llama.cpp 不同版本的启动参数可能有变化，以你下载的那个版本为准。旧命令失效时，把旧命令（作用：加载模型、开嵌入模式/池化、设端口）发给 AI，让它按你的新版本生成新命令；对不对以能不能跑起来为准——命令行出现 listening on http://... 即成功。
